# 1장 · 문진 폼 · 20분

## 이 장이 끝나면

- 12문항 폼을 직접 만든다
- 내 답변이 `state/intake.json` 으로 들어간다

---

## 왜 화면부터 만드나

보통 순서와 반대입니다. 이유는 하나입니다. **재료가 없으면 뒤가 전부 남의 것이 됩니다.**
강사 예제로 실습하면 마지막 화면의 준비 목록이 내 것이 아닙니다.

---

## 백지 회상은 실패합니다

"어떤 지적을 자주 받으셨나요?" 라고 물으면 대부분 두세 개 쓰다 맙니다.
사람은 백지에서 못 떠올립니다. **보기를 주면 떠올립니다.**

그래서 이 폼의 중심은 12개 보기 다중선택입니다. 자유 서술은 보조로만 씁니다.

> 이건 에이전트에게 물을 때도 똑같습니다. 열린 질문보다 선택지가 정확한 답을 뽑습니다.
> 오늘 만드는 프롬프트 전체가 이 원리 위에 있습니다.

---

## 실습

Claude Code 에 아래를 그대로 붙여넣습니다.

```
web/intake.html 을 만들어줘. 의존성 없는 단일 HTML 파일이다. 저장 기능은 쓰지 않는다.

12문항 폼을 만든다.

A. 대상
 1. 이 문서를 최종 승인하는 사람 (이니셜로) — 필수
 2. 보고 형태 — 구두 회의 / 문서 회람 / 메신저 / 대면 1:1

B. 반려 경험
 3. 아래 중 실제로 들어본 말을 모두 고르세요 (체크박스 12개)
    "이 숫자 어디서 나왔어요?" / "결론이 뭐예요?" / "대안은 없어요?" / "너무 길어요"
    "이거 누가 하는 거예요?" / "언제까지예요?" / "비용은요?" / "리스크는요?"
    "전에 했던 거랑 뭐가 달라요?" / "다른 팀이랑 얘기됐어요?"
    "그래서 나한테 뭘 해달라는 거예요?" / "이거 왜 지금이에요?"
 4. 체크한 항목 아래에만 빈도 선택이 펼쳐진다 — 4회 이상 / 2~3회 / 1회 / 기억 안 남
 5. 위 보기에 없는데 자주 들은 말 (쉼표 구분, 3개까지)
 6. 되돌아온 문서와 통과된 문서의 차이 한 줄

C. 통과 조건
 7. 한 번에 통과된 문서가 있다면 무엇이 달랐나 (자유)
 8. 이 사람이 문서에서 먼저 보는 곳 — 첫 장 / 숫자 표 / 결론 / 일정 / 모름
 9. 싫어하는 게 확실한 것 (자유, 비워도 됨)

D. 이번 문서
 10. 이번에 보고할 문서의 목적 한 줄 — 필수
 11. 이번 문서에서 스스로 불안한 지점
 12. 초안 텍스트 (큰 textarea. 비우면 "없음")

요구사항:
- 필수는 문항 1과 10 둘뿐. 나머지는 전부 건너뛸 수 있다
- 상단에 "n / 12 답변함" 진행 표시. 필수 2개가 비면 복사 버튼 비활성화
- 하단에 큰 버튼 [답변 복사하기]. 누르면 JSON 한 덩어리를 클립보드에 복사한다
- ★ 답 안 한 문항은 빈 문자열로 넣지 말고 skipped 배열에 문항 번호를 넣는다
- JSON 키: reviewer, report_form, heard[{q,freq}], heard_free[], diff_rejected_vs_passed,
  passed_why, reads_first, dislikes, doc_purpose, my_worry, draft, skipped[]

스타일: 무채색, 시스템 폰트, 1px 괘선. 화면 폭 720px 중앙 정렬.
```

---

## 이 폼의 유일한 기술적 요구

**답 안 한 문항을 `skipped` 배열로 분리하는 것.**

빈 문자열로 넘기면 "답이 없다" 와 "안 물어봤다" 가 섞입니다.
그러면 나중에 시스템이 "정확도를 올리려면 3번과 7번에 답하세요" 를 계산할 수 없습니다.

프롬프트에 ★ 로 표시한 줄이 그것입니다.

---

## 답하고 복사

```bash
./scripts/serve.sh
```

`http://localhost:8080/web/intake.html` 에서 **기억나는 만큼만** 답합니다.
문항 12(초안)는 일단 비워 두세요. 8장에서 채워 넣고 결과가 어떻게 달라지는지 봅니다.

[답변 복사하기] 를 누르고, Claude Code 에 붙여넣습니다.

```
/intake  { 여기에 붙여넣기 }
```

`state/intake.json` 이 생기면 됩니다.
